# Ordena

Juego 3 (§12). Ordenar pasos de un proceso.

- Los números de la izquierda son fijos; los pasos se reordenan a su lado.
- Arrastre con mouse o táctil (dnd-kit), teclado (foco en el paso → `Espacio` tomar, `↑` `↓` mover, `Espacio` soltar, `Esc` cancelar) o botones ↑ ↓ en cada paso. Anuncios para lector de pantalla en español.
- Envío con botón **Comprobar** (`Enter`).
- Pista: el servidor indica dónde va un paso (`{ stepId, position }`).

| Nivel | Pasos | Tiempo |
| ----- | ----- | ------ |
| 1     | 4     | 45 s   |
| 2     | 5     | 50 s   |
| 3     | 6     | 55 s   |

**Decisiones:** número y paso comparten una fila de una sola grilla, así el texto nunca se corta y el número queda alineado. El mock exige todos los pasos en su lugar para sumar puntos.
